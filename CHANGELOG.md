# Changelog

## 0.1.0 (fundação)
- Tokens LopFlow v2, tema escuro opcional.
- Componentes standalone Angular 21+ (APF partial).
- Skeleton, DataTable, ServerPager, DirectoryFilter, State, Toast,
  CollapsibleCard, AreaSidenav, CommandPalette e EntityPicker.
- CLI JSON para agentes, templates e testes.
- CI apenas por PR ou execução manual.

- Primitivas visuais de chat, cartões Kanban, campos de formulário e
  badges de estado (sem mover lógica de streaming ou CRM).

## 0.1.1 (licenciamento e distribuição)
- Migra AGPL-3.0-only para licença permissiva MIT, inclusive nos pacotes distribuídos.
- Atualiza documentação/manifesto de licença e testes.
